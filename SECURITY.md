# Security

This library reads loan files that may contain confidential data, and its MCP server gives an AI
agent read access to a folder. If you find a way to make it read outside that folder, write a file,
reach the network, run code or exhaust memory, or a calculation that silently returns a wrong number
for valid input, please do not open a public issue. Write to research@eqlx.ai or use GitHub's
"Report a vulnerability" button on the Security tab. Never send real loan data; describe the case or
reproduce it with `eqlx-portfolio sample`. We aim to reply within five working days.
